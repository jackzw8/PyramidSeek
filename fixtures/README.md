# fixtures（示例数据）

**用途**：
1. 离线跑通整链——任何改动不得破坏「仅用 `fixtures/` 跑通」（家法 R16 / 计划 M0）；
2. 作为 **M2-6 黄金样本**输入——Python 与 JS 双引擎跑同一份数据，逐项对账。

**文件**：`financials.json`（12 只股票：A股 8 + 港股 4；标准层财报字段见《数据字典》§3.2）。

**口径**：金额「亿元、2 位小数」，比率存小数，空值 `null`（**不是 0**）；勾稽精确成立 `total_liabilities = total_assets − equity`；`effective_date = report_period + 4 个月`。

**数据性质**：示意数据（非真实财务口径），`industry_std` / 行业代码为示意占位，M1 接入数据源后以真实分类树覆盖。港股按 ADR-011 走降级路径（东财口径先行、`industry_std` 标注「待校准 GICS」）。
